# Торговый бот Bybit

`trading_bot.py` — компактный скрипт для торговли бессрочными фьючерсами Bybit.
Он повторяет изначальную EMA/RSI-идею и добавляет понятный CLI, безопасные
уведомления в Telegram и защиту от сетевых сбоев.

## Установка зависимостей

```bash
pip install ccxt pandas numpy ta matplotlib requests
```

## Быстрый старт

* Запустите быстрый бэктест по инструментам по умолчанию:
  ```bash
  python trading_bot.py --mode backtest
  ```
* Перейдите в live-режим (нужны переменные окружения `BYBIT_KEY` и `BYBIT_SECRET`):
  ```bash
  python trading_bot.py --mode live --verbose
  ```

## Полезные опции

* `--symbols` — список тикеров через пробел, например `--symbols BTC/USDT:USDT ETH/USDT:USDT`;
* `--mainnet` — переключение с тестнета на рабочую биржу;
* `--start-equity` — размер счёта для расчёта позиций в бэктесте (по умолчанию 10 000 USDT);
* `--stop-file` — путь к файлу, создание которого остановит бота в live-режиме.

Перед запуском в реальной торговле протестируйте стратегию и убедитесь, что
риск-параметры подходят вашему плану.
